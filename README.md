# عيادة ابتسامة — تطبيق الهاتف

نسخة PWA تجريبية لعيادة د. آلاء حريم.

- افتح رابط الموقع على الهاتف.
- Android: اختر تثبيت التطبيق من المتصفح.
- iPhone: افتح في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.

تنبيه: نموذج الحجز يرسل الطلب عبر WhatsApp. المحادثة ولوحة الإدارة غير متصلتين بذكاء اصطناعي أو قاعدة بيانات مرضى فعلية.
